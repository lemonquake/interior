This game uses a modified version: engine-scale normalization, a golden coat
texture, subtle fur normal texture, rounded ear tips, fine whiskers, quadruped
skinning, eight animations, and three runtime coat variations. The original
mesh was downloaded through the public Allen Institute Objaverse distribution;
its embedded Sketchfab metadata identifies the same author, source, and license.

See `provenance.json` for the download URL and SHA-256 hashes. Reproduce the
modified GLB with `tools/prepare_hamster.py` in Blender 5.2. Downloaded source
bytes and the editable Blender rig are preserved under the private work folder.

The newly authored enclosure and behavior code are part of this game project.
Oak maps are authored by this project; see the shared surface assets.
