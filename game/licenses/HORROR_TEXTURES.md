# Horror prop and red liquid textures

Created for Sleep on 2026-10-26 using OpenAI's built-in imagegen tool.

Six generated prop surface maps are stored in `assets/horror_textures/props/`:
wrinkled black refuse plastic, scuffed tintable plastic, wet cardboard, discarded
paper, tarnished metal and stained woven fabric.

Three generated RGBA graphics are stored in `assets/horror_textures/liquid/`:
impact splatter with drips, drag smear and irregular pool. Their original alpha
channels are preserved. No third-party reference images were used to generate
these nine assets. Existing imported prop textures retain their original credits.

The exact generation prompts and source SHA256 hashes are in the project's
`docs/horror-textures/` folder. No new third-party attribution requirement is
introduced by these generated assets.
