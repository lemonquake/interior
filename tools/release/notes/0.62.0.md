# 0.62.0
- Play online without a VPN: Host game now opens your squad through the Sleep server, so friends join from their list behind any ordinary home router or on mobile data. No Radmin, no port forwarding.
- The online lobby runs on the Sleep server first, so everyone sees the same list of games and the same chat.
- Friends on the same Wi-Fi still connect straight to the host.
- The new Sleep launcher installs the game, checks for updates every time it opens and downloads only what changed.
- New voice lines for the whole squad, with the right emotion for every moment.
- Getting hurt shakes your view a little and flashes it red.
- Real 3D litter scattered through the canal slum.
- PILCST doorways are never blocked by chairs: keep walking and you wade through, and T shoves chairs out of the way.
